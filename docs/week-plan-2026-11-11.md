# Тижневий план 11–16.11.2026 (переписаний під реальний стан репо)

Стан на 11.11: M0–M1 готові (монорепо, CI, Prisma, сід). Немає: auth, shipments API, вебхуків, фронтенду, деплою.
Ціль тижня: робоче демо-посилання з дашбордом — це те, що наближає до офера.
Stationery-продукт переноситься на наступний тиждень.

## Правила на весь тиждень

- Один milestone = окремий план `docs/superpowers/plans/2026-11-XX-mN-*.md` у форматі плану M1.
- Планування: головна сесія `/model fable`, `/effort xhigh`, plan mode → ти погоджуєш план.
- Виконання: Fable `/effort high` як контролер, субагенти на Opus
  (`.claude/settings.json` → `"env": { "CLAUDE_CODE_SUBAGENT_MODEL": "opus" }`).
- `git commit/push` робиш тільки ти (CLAUDE.md). Після кожної задачі — рев'ю + твій коміт.
- Хмарні сесії — лише якщо додаси в CLAUDE.md виняток для гілок `claude/*`; інакше все локально у VS Code.
- «Мінімум дня» — що має бути готово, навіть якщо день пішов не за планом.

## Ср, 11.11 — M2: auth

- Fable: brainstorming по §7 (JWT lifetime, CSRF double-submit, error-handler plugin, rate limit, Zod у shared).
- Ти приймаєш рішення (human checkpoint §12.7) → план `2026-11-11-m2-auth.md` → виконання.
- Включити: централізований error handler `{ error: { code, message } }`, вирівняти версію typescript між workspaces.
- **Мінімум дня:** погоджений план M2 + register/login/me/logout з інтеграційними тестами.

## Чт, 12.11 — M3: shipments + state machine

- State machine (`apps/api/src/lib/state-machine.ts`) — TDD, 100% переходів, включно з self-loop і EXCEPTION-recovery.
- CRUD + `POST /shipments/:id/events`, ownership-перевірки в service layer (клієнт не бачить чужі відправлення).
- Фільтри `status`, `search`, `page` — під майбутній дашборд.
- **Мінімум дня:** state machine + `GET /shipments` (list/detail) з access control тестами.

## Пт, 13.11 — M4: вебхуки + mock-інтерв'ю

- Ранок: `POST /webhooks/carrier` (HMAC по raw body, 401/404/422, ідемпотентність) + `scripts/simulate-carrier.ts`.
  Окремий checkpoint (§12.7) — контракт вебхука погоджуєш до реалізації.
- Вечір (≈1.5 год): Fable mock-інтерв'ю, 10–15 найслабших питань з трекера.
  Додати 3 питання по своєму коду: «чому HttpOnly cookie + CSRF», «як зробив ідемпотентність», «чому event log append-only».
- **Мінімум дня:** вебхук + симулятор + тести; mock-інтерв'ю не пропускати.

## Сб, 14.11 — M5: фронтенд-основа

- Додати у `apps/web`: Tailwind, Zustand, React Hook Form + Zod resolver, Framer Motion.
- API client (`credentials: 'include'`, `X-CSRF-Token` з cookie), сторінки `/login`, `/register`, захист роутів.
- **Мінімум дня:** логін демо-юзером працює end-to-end локально.

## Нд, 15.11 — M6: дашборд (головна вітрина для фронтенд-співбесід)

- `/shipments`: таблиця, статус-бейджі (EXCEPTION — помітний), фільтри + пошук, пагінація, skeletons, empty states.
- `/shipments/[id]`: картка + вертикальний таймлайн (Framer Motion), форма ручного статусу лише з легальними переходами.
- `/shipments/new` для диспетчера (RHF + shared Zod).
- **Мінімум дня:** список + деталь з таймлайном. Форма створення може переїхати на пн.
